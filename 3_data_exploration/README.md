# 3_data_exploration

This folder contains exploratory data analysis (EDA) on the merged dataset.

## Objectives

- Summarize dataset structure and missingness.
- Explore key categorical variables such as project type, country, and energy
  source.
- Visualize distributions of maintenance costs and generator runtimes.

## Files

- `summary.txt` — text summary of dataset structure and missing values.
- `plots/` — exported images of the main charts.

## Notes

- Analysis is kept lightweight, focusing on simple descriptive summaries and
  basic charts.
- Results will guide deeper analysis in later stages.
